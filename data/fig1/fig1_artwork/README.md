# fig1_artwork

Figure 1: the page's artwork, which no code draws, as the author made it (artwork pasted in Illustrator; not drawn by code) -- panel a; and parts of panels c and d.

`artwork.png`: the whole page, 3400 x 4400 px (400 dpi, 8.5 x 11 in), transparent wherever the artwork draws nothing. The page script, `code/fig1/fig1_page.py`, draws it over the panels, so the rendered page is complete. It is an image of the artwork, not source data: where it shows a plot the author made, the plot's values are not in data/.

It holds:

- a: the cage and camera drawing and "Label accuracy"
- c, right: "ID accuracy"
- d: Animal 1's head icon
- d: Animal 2's head icon
- d: Animal 3's head icon
- d: Animal 4's head icon
