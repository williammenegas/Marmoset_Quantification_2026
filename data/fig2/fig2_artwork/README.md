# fig2_artwork

Figure 2: the page's artwork, which no code draws, as the author made it (artwork pasted in Illustrator; not drawn by code) -- panel c; and parts of panel d.

`artwork.png`: the whole page, 3400 x 4400 px (400 dpi, 8.5 x 11 in), transparent wherever the artwork draws nothing. The page script, `code/fig2/fig2_page.py`, draws it over the panels, so the rendered page is complete. It is an image of the artwork, not source data: where it shows a plot the author made, the plot's values are not in data/.

It holds:

- c: the model schematic
- d: the dashed bed circles and the "Bed" label
