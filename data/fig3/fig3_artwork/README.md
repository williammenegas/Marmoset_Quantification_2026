# fig3_artwork

Figure 3: the page's artwork, which no code draws, as the author made it (artwork pasted in Illustrator; not drawn by code) -- parts of panel a.

`artwork.png`: the whole page, 3400 x 4400 px (400 dpi, 8.5 x 11 in), transparent wherever the artwork draws nothing. The page script, `code/fig3/fig3_page.py`, draws it over the panels, so the rendered page is complete. It is an image of the artwork, not source data: where it shows a plot the author made, the plot's values are not in data/.

It holds:

- a: Animal 1's hair-colour icons
- a: Animal 2's hair-colour icons
