# figS2_artwork

Figure S2: the page's artwork, which no code draws, as the author made it (artwork pasted in Illustrator; not drawn by code) -- panel a; and parts of panels b, d and f.

`artwork.png`: the whole page, 3400 x 4400 px (400 dpi, 8.5 x 11 in), transparent wherever the artwork draws nothing. The page script, `code/figS2/figS2_page.py`, draws it over the panels, so the rendered page is complete. It is an image of the artwork, not source data: where it shows a plot the author made, the plot's values are not in data/.

It holds:

- a: the camera and depth schematic
- b: the photograph
- d: the photograph
- f: the photograph
