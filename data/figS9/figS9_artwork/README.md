# figS9_artwork

Figure S9: the page's artwork, which no code draws, as the author made it (artwork pasted in Illustrator; not drawn by code) -- panels b and c.

`artwork.png`: the whole page, 3400 x 4400 px (400 dpi, 8.5 x 11 in), transparent wherever the artwork draws nothing. The page script, `code/figS9/figS9_page.py`, draws it over the panels, so the rendered page is complete. It is an image of the artwork, not source data: where it shows a plot the author made, the plot's values are not in data/.

It holds:

- b: the draft's call-type spectra
- c: the draft's call examples
